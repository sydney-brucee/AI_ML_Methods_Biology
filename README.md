# AI/ML Methods Applied to Biology and Medicine

Jupyter notebooks from a course covering statistical and machine-learning methods with applications in biology and medicine.

## Skills Demonstrated
- Maximum likelihood estimation and confidence intervals
- Hypothesis testing and model comparison (AIC, likelihood ratio tests)
- Resampling, bootstrapping, and distribution fitting
- Regression and categorical data analysis

## Topics Covered
- Confidence intervals and estimation
- Chi-square tests and regression
- Likelihood-based inference
- Model selection and hypothesis testing

Code is organized by homework assignment and includes both the notebooks and exported HTML versions.
